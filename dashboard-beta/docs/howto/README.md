Step by step, one job per page: what to press, what to type, and what you
should see when it worked. Every page says how to do the same thing from
the command line, because `node tools/okc.js <action>` is the same surface
as the window.

- [Build a machine](build-a-machine.md)
- [Sign a machine in to Claude](sign-in-a-machine.md)
- [Write and run a task](write-and-run-a-task.md)
- [Hand an issue to the supervisor](hand-an-issue-to-the-supervisor.md)
- [Send a drafted reply, close or review](send-a-drafted-reply.md)
- [Cut a pull request](cut-a-pull-request.md)

- [Judge a pull request from outside](judge-a-pull-request-from-outside.md)
- [Approve a skill change](approve-a-skill-change.md)
- [Run the drills](run-the-drills.md)
- [Refresh the bootstrap tar](refresh-the-bootstrap-tar.md)

If a page here does not match what the window does, the window is right and
the page is wrong — fix the page.
