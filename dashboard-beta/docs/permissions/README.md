# Permissions

What a person may do, what a machine may do, and where the line is drawn —
and why each refusal says what it says.

The shape, in one paragraph: some presses are a person's, and the app refuses
them to the command line, to a machine and to a driven window alike — the
refusal names the reason. Purple is how one of those is **marked** on screen:
a purple button, a field with a purple outline. The two are not the same set,
and the refusal is the one that stops anything; releasing a drafted reply is
refused and is not painted. A setting listed as "at the window" is the same
idea for a value rather than a press. Everything else is one surface: the
window, the command line and the next person use the same actions with the
same rules.
