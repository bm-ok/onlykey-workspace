# Queue

The Queue tab: tasks and judgements, what is waiting, what is running on
which machine, and what came back. The queue ticks on its own, drives the
same actions a person does, and puts every machine back to its base
snapshot after a run.

- [How the queue runs](how-the-queue-runs.md) — one tick, restarts, stopping, what can go quiet
- [Tasks](tasks.md) — what a task carries, its life, sessions
- [Judgements](judgements.md) — what is judged, the verdict line, what follows it, stale readings
- [The library](library.md) — jobs, prompts, contracts, and approval
