# Repositories

The Repositories tab: the workspace's repositories, their forks and the
project above them, branches, lines, cuts and pull requests, and the issues
and pull requests read from GitHub.

- [Workspace, forks and the chain](workspace-and-forks.md) — where work is sent, where issues are read from, keeping in step
- [Branches, lines and cuts](branches-lines-and-cuts.md) — three words, three things, and the panes named after them
- [Pull requests and cuts](pull-requests-and-cuts.md) — what this host sends, what arrives, the template, closing an issue
- [Issues](issues.md) — the Issues pane, tags, drafts, arrivals
- Sync — the whole workspace caught up in one place: forks against where
  their work goes, this host against the forks, the lines; see the end of
  [Cut a pull request](../howto/cut-a-pull-request.md)

Panes, left to right: Overview, Repos, Sync, Issues, Pull requests, Conflicts,
Branches Cut, Branches Lines, Changes, Protected, PR cuts, New PR Cut,
Graph.
