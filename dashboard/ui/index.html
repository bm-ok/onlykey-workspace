Terminal

Started from a task, and they arrive here. Over ssh, with this app's own key — the same way in as okc.js vmShell and the same way VS Code connects, so if one works they all do.

Worker sign-in

One machine is signed in by you; the credential is taken from it and kept here. Every other machine is handed a copy when it needs one — so a credential is part of a task rather than part of a machine, and a machine that is deleted or snapshotted takes none with it.

GitHub

Used by this host only. A machine pushes to this app's own git server and never to GitHub, so no runner is ever handed this token — which is why rolling one back cannot lose it.
